# Country Game

Un jeu de QCM (questions à choix multiples) de culture générale sur les pays du monde.

**Jouer en ligne :** [https://mathieu-grasset.github.io/Country-Game/](https://mathieu-grasset.github.io/Country-Game/)

## À propos du jeu

Le jeu propose des questions générales sur les pays : géographie, données démographiques, économie, culture, etc.

Certaines questions portent sur des valeurs chiffrées (population, superficie, PIB, etc.). Ces valeurs varient selon les sources et évoluent dans le temps ; en raison de cette versatilité et de la pluralité des sources existantes, **c'est la valeur la plus proche de la bonne réponse qui est considérée comme correcte**, plutôt qu'un chiffre unique et figé.

## Version WebGL vs exécutables

Le jeu a été conçu à l'origine pour des exécutables **macOS** et **Windows**. La version WebGL présentée ici permet d'y jouer directement dans un navigateur, mais certaines fonctionnalités des versions exécutables ne sont pas disponibles en WebGL, notamment **la sauvegarde de la progression**.

## Images

Les images utilisées pour illustrer les pays sont **générées par IA**.

## Technique

Ce jeu est développé avec Unity et exporté en WebGL, ce qui permet d'y jouer directement dans un navigateur sans installation.
